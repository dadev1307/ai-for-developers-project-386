# Календарь звонков

Сервис для бронирования времени звонков: гость выбирает свободный слот и записывается на звонок. Единый контекст домена для всего репозитория.

## Language

**Booking Window** (окно записи):
Период, в пределах которого гость может выбрать время события: 14 календарных дней, начиная с сегодняшнего дня.
_Avoid_: горизонт бронирования, период записи

**Buffer** (буфер):
Минимальный промежуток между событиями; общий параметр окна записи, по умолчанию 0 минут.
_Avoid_: пауза, перерыв

**Call Calendar** (Календарь звонков):
Название сервиса. В интерфейсе отображается как «Календарь звонков», в шапке страницы — короткий вордмарк «Calendar».
_Avoid_: Calendar (как канонический термин в речи и документации)

**Event** (событие):
Забронированный звонок в календаре. Возникает, когда гость записывается на звонок.
_Avoid_: бронь, запись, встреча

**Event Type** (тип события):
Настраиваемая владельцем разновидность звонка: название, описание и длительность в минутах. Гость выбирает тип события, чтобы записаться на звонок.
_Avoid_: вид события, услуга, встреча

**Slot** (слот):
Возможный старт события — момент из сетки стартов с шагом 30 минут внутри рабочих часов.
_Avoid_: окно (пересекается с «окном записи»), интервал (слот — момент, а не промежуток)

**Working Hours** (рабочие часы):
Ежедневный интервал 09:00–18:00 по московскому времени, единый для всех дней недели; события начинаются и заканчиваются внутри него.
_Avoid_: приёмные часы, график владельца
